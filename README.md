# Schnyder Woods on Toroidal Triangulations

**[Read the paper (PDF)](paper.pdf)**

Undergraduate research project, École Polytechnique, Feb–Jun 2026.
Supervised by Prof. Luca Castelli Aleardi.

## Results

- A new linear lower bound on the number of sources in minimal
  toroidal Schnyder woods for triangulations.
- A purely combinatorial proof that every balanced Schnyder wood
  contains a clockwise and a counterclockwise contractible triangle,
  previously established by homological methods.
